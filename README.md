# RetroPixel Store 🎮

Sistema de gestión de inventario para una tienda ficticia de videojuegos y películas, desarrollado en Python como proyecto académico de UADE.

## 📌 Descripción

La aplicación permite administrar un catálogo de productos mediante una interfaz de consola, incluyendo operaciones de alta, modificación, eliminación, búsqueda y consulta de información.

El proyecto fue desarrollado aplicando programación modular, estructuras de datos y validación de entradas.

## ⚙️ Funcionalidades

* Registrar productos manualmente o generar datos aleatorios
* Modificar y eliminar productos
* Validar títulos duplicados
* Buscar productos
* Administrar categorías y plataformas
* Consultar el catálogo completo
* Calcular el precio promedio por categoría
* Identificar la plataforma con mayor cantidad de productos
* Generar reportes mediante matrices
* Ordenar productos según stock
* Validar datos ingresados por el usuario

## 🧩 Estructura del proyecto

```text
RetroPixelStore/
├── mainTPO.py
├── FuncionesTPO.py
├── DatosTPO.py
├── MenusTPO.py
└── README.md
```

* **`mainTPO.py`** — Punto de entrada y flujo principal del programa.
* **`FuncionesTPO.py`** — Lógica de negocio, validaciones, búsquedas, reportes y operaciones sobre los productos.
* **`DatosTPO.py`** — Datos iniciales y opciones disponibles.
* **`MenusTPO.py`** — Menús e interacción con el usuario.
